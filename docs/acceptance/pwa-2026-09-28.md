# Installable Jevellan · 2026-09-28

The user requested a complete PWA experience. This iteration follows BRIEF section 15 and preserves the instruction not to run tests for new features.

## Implemented

- A navy, white and magenta J icon, with SVG, 192/512 PNG, an opaque maskable icon, 180-pixel Apple touch icon and 32-pixel favicon. The essential mark fits inside the maskable safe circle.
- A versioned manifest validated with Zod during the build, stable application identity, standalone display, scope, launch URL, theme colours and productivity metadata. Apple home-screen metadata and phone safe-area spacing are included.
- An Install app entry and Settings → About installation guidance. Browsers exposing their install prompt can install directly; Safari and other browsers retain their native menu flow. Installed windows hide the install entry.
- A service worker version derived from the built public files, with an explicit asset allowlist. Offline navigation shows a dedicated reconnect screen, including when the host returns a server error or takes more than eight seconds to respond. Existing windows show an offline notice when the browser detects lost connectivity.
- App updates show Reload/Later; there is no forced reload. Activation reloads only the window whose user requested it. One previous public asset cache is retained for existing windows, and legacy caches are removed. A returning visible window checks for updates at most once per minute.
- API, hub, device-switch and non-GET requests are excluded from service-worker handling. Conversation content and authentication responses are not put in its caches; messages are not queued offline.
- Correct PNG/font content types, revalidation for HTML/manifest/worker, immutable caching for Vite assets and explicit service-worker scope.

The design uses existing browser capabilities with no PWA framework or new runtime dependency. Installation still requires HTTPS (or localhost), and remote access still requires the existing tailnet connection and running host. The app does not install an OS service or change CSG's transport.
