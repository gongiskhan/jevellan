# Cursor feedback repair — 2026-09-28

The user reported missing feedback during CSG work, raw timestamp markup in session titles and empty-looking tool calls. The open browser reproduced the title defect and almost-white tool text on a pale background. Read-only inspection found that CSG's journal contained tool inputs but no tool results, and lagged behind live hook activity. Historical tools were incorrectly presented as running.

The repair strips Cursor's timestamp/context envelopes from user messages and titles, uses the application's code foreground/background pair, and labels journal-only tools as recorded without inventing a result. Hooks now capture tool results, failures, responses and thinking into a versioned isolated activity document. It retains at most 40 entries for the current generation, bounded to 256,000 serialized characters, with individual fields truncated visibly at 32,000 characters. New generations clear the feed. Native journals remain read-only. The UI presents these as live updates, keeps working feedback beside the composer, follows new content when at the bottom and offers Jump to latest while reading history.
