## Fixes

- `runtimes/claude/src/worker.ts`: an error result's reason comes from `errors` or, failing that, from `result`. Regression test: `tests/runtime-adapters.test.ts`, "Claude keeps the reason of an error result".
- `packages/conversations/src/execution.ts`: the code-written failed handoff appends the redacted runtime error. Regression test: `tests/stretch-execution.test.ts`, "a code-written handoff carries the runtime failure reason".

Open design question: a model-specific usage limit is still classified `other`, not `rate-limit`. This is deliberate. Account-level cooling would also block Opus on the same account, and model-level cooling does not exist yet.

Earlier simulated evidence: `tests/decision-selection.test.ts` covers the notice itself with fixtures.
