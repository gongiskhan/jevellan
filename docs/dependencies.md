# Dependencies and redistribution

Jevellan and the source Garrison project are MIT licensed, copyright 2026 Gonçalo Gomes. Garrison's license and NOTICE are retained.

Direct registry metadata inspected during phase 0: React, React DOM, Vite, Vitest, zod, tsx and the MCP SDK report MIT; TypeScript, Playwright and the Codex SDK report Apache-2.0; YAML reports ISC. Preserve package license files when distributing dependencies. Transitive license inventory remains part of the final packaging verification.

Phase 1 adds node-pty 1.1.0 and @xterm/headless 6.0.0 (MIT), plus smol-toml 1.9.0 (BSD-3-Clause). Keep their package license notices in installed copies. APM 0.10.0 was the installed tool used for the delivery checks.

The npm package roots for xterm/headless 6.0.0 and Codex 0.156.1 omit upstream notices. Unmodified license texts and Codex's OpenAI/Ratatui NOTICE are retained under [docs/licenses](licenses/README.md), with matching-tag source links and checksums. Codex's Darwin ARM64 package also contains a voice-component NOTICE, seven license texts, a source inventory with archive URLs and checksums, and a build manifest. Those nested notices cover additional licenses, including LGPL-2.1, and must stay with the separate native libraries. Four fresh packed installations verified preservation of 227 notice files, including both sets; see [the installed-copy receipt](acceptance/J9-installed-notices.json).

Phase 5 adds tar 7.5.22 (BlueOak-1.0.0, checked against installed package metadata) for extracting the pinned uv archive without a shell installer. The installer pins uv 0.11.23, APM 0.10.0, Basic Memory 0.22.1 and managed Python 3.12. Installed wheel metadata identifies APM as MIT and Basic Memory as AGPL-3.0-or-later; their upstream license files stay in their private Python installations. Basic Memory is an external process and is not relicensed as Jevellan source. See [dependency installation evidence](acceptance/phase5-tools.md).

The Settings UI uses react-markdown 10.1.0 and remark-gfm 4.0.1 (MIT, checked against installed package metadata). Raw HTML is disabled. Markdown rendering loads on demand rather than in the initial application bundle.

Repository operations use the machine's Git executable. Prepared undo requires `merge-tree --write-tree --merge-base`, `commit-tree` and fast-forward merge support. Actual repository tests pass with Apple Git 2.50.1; they do not establish a minimum compatible version. The installer now checks the available Git and its `merge-tree --write-tree --merge-base` capabilities, accepting Git's `--[no-]` help notation. The doctor command uses the same Git capability check and checks installed dependencies in a disposable isolated probe home.

The Claude Agent SDK reports "SEE LICENSE IN README.md". Its installed LICENSE.md states that Anthropic reserves all rights and links to its legal agreements; it is not MIT or Apache licensed. Inspection of the actual packed archive on 2026-09-25 found that npm's transitive bundling includes this SDK and its platform binary. The earlier statement that these files were external to the archive was incorrect. They are not relicensed as Jevellan source.

The public delivery target is the GitHub source repository. Dependency directories, compiled output and packed archives are excluded from that repository. The documented GitHub install command fetches and prepares dependencies on the installing machine; updates prepare a GitHub-source package there too. Private installation and test archives contain those dependencies with their original notices, and the installer copies the entire prepared tree with a digest check. This run does not publish an npm package or a binary release. See [the archive inventory](acceptance/phase5-license-inventory.md) for the scope of the installed-copy verification.

Anthropic's current documentation permits preinstallation under conditions tied to its Commercial Terms, an unmodified binary and each user's own authentication. That conditional permission is not an open-source license for the SDK, nor a claim that the owner has accepted an agreement. Technical login compatibility is separate from these terms. See [Anthropic's legal and compliance documentation](https://code.claude.com/docs/en/legal-and-compliance).

The 2026-09-26 interface overhaul bundles four self-hosted web fonts from the project website: Bricolage Grotesque, Geist, JetBrains Mono and EB Garamond (italic). All four are licensed under the SIL Open Font License 1.1; the license text ships in the built application as `fonts-OFL.txt` (source: `apps/web/public/fonts-OFL.txt`). No font is loaded from a third-party network location.
