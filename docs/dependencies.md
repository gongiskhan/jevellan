# Dependencies and redistribution

Jevellan and the source Garrison project are MIT licensed, copyright 2026 Gonçalo Gomes. Garrison's license and NOTICE are retained.

Direct registry metadata inspected during phase 0: React, React DOM, Vite, Vitest, zod, tsx and the MCP SDK report MIT; TypeScript, Playwright and the Codex SDK report Apache-2.0; YAML reports ISC. Preserve package license files when distributing dependencies. Transitive license inventory remains part of the final packaging verification.

The Claude Agent SDK reports "SEE LICENSE IN README.md". Its installed LICENSE.md states that Anthropic reserves all rights and links to its legal agreements; it is not MIT or Apache licensed. Jevellan references the SDK as an external npm dependency and does not copy its source or license it as part of Jevellan. The final packaging check must preserve this dependency boundary and upstream notices. Technical login compatibility is separate from license and provider-term permission.
