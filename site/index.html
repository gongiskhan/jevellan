The reef every agent hits

Long sessions drift.

The context fills up, the model loses the thread, and someone has to steer by hand. Usually you, at 1 a.m.

The navigator

Meet Jev. It can't write a single line.

That's the point. Jev is TypeSafe AI's System One model. Hand it the situation and a few typed questions, and it answers each one with a pick and calibrated probabilities, in about a tenth of a second. Your agents write. Jev decides.

Jevellan asks: the next step, the model, the effort.

A yes-or-no question, answered with how likely yes is.

Jevellan asks: stay on the current model? did you ask me to remember that?

A rating on your own levels. Answers can land between them.

How we got here

A fair wind, right on course.

A fair wind blows exactly where you're already heading. We were halfway down the coast, looking for the passage, when Jev showed up.

Before Jev

We built the ship.

It was called Garrison: an orchestrator for Claude Code and Codex. It already ran work in short stretches with handoffs, kept a ledger, spread work across accounts on different providers and joined several machines into one mesh. Short, focused stretches were already giving us better work for fewer tokens than one long session.

Every inlet, a dead end

The hard part was the moment between steps.

What next? Which model? How much effort? We wrote duties, levels, routing tables and flows, plus a Haiku call for the ambiguous cases. The rulebook kept growing. The decisions didn't get much better.

Then Jev came along.

TypeSafe released a model built for exactly that moment: fast, typed decisions with honest probabilities. It slid into the gap we'd left, like the slot had been cut for it. Serendipity doesn't usually come with an API.

Now

Jevellan: through the strait.

We kept the timbers that worked, threw the rulebook overboard and gave Jev the helm. Everything you don't need for building software stayed ashore.

The change of watch

Every handoff, Jev gets asked.

When a stretch hands over, Jevellan lays out the facts and asks Jev a handful of typed questions. Code handles everything that's about resources and limits.

  1. 1stretch

    The handoff lands

    Status, summary, evidence, findings and a suggested next step. It's evidence, not an order.

    status: donetests: passednext?: review
  2. 2code

    Code lays out the chart

    Which actions are allowed now, which models have an account ready, and plain facts instead of numbers.

↩repeat at the next handoff, until landfall

Jevdecides meaning.

  • The next step, from the actions code allows right now.
  • The model, reading the one-line description you wrote for each.
  • The effort, separately, because the same model fits easy and hard work.
  • The memory worth bringing along for this step.

Codedecides resources.

  • Which account pays: logged in, under its ceiling, allowed to spend.
  • Guards: step limits, no-progress, repeated test failures, a cost cap.
  • Git: checkpoints, its own test run, and publishing only when it passes.
  • Where it runs: the machine you started on, in the exact checkout you set up.
Jev never compares numbers.Code turns them into facts first: “large change”, not “14 files”.

Your routing profile

plain words · editable
  1. Prefer staying on the current model when it fits the next step.
  2. UI, visual work and anything judged by looking goes to Fable.
  3. Long, well-specified implementation prefers GPT through Codex.
  4. Review only when the change is large or risky. Prefer a reviewer from a different model family.
  5. Effort follows difficulty, not importance.

The signal book

Every step flies a flag.

The italic meanings are the real ones from the International Code of Signals. We checked. Some fit a little too well.

In 1519 Magellan, a Portuguese navigator sailing for the Spanish crown, kept five ships together at night with one light burning on his flagship, the farol, and a few lantern signals. Two lights meant change tack. Three meant shorten sail. Every ship answered in kind. Jevellan does the same for your agents, with flags.

replyK · KILO

“I wish to communicate with you.”

Answer you. No changes.

planP · PAPA

“All persons should report on board, as the vessel is about to proceed to sea.”

Work out the route before touching anything.

implementI · INDIA

“I am altering my course to port.”

Make or fix the change.

testT · TANGO

“Keep clear of me.”

Run the tests and add the missing ones.

reviewR · ROMEO

No single-flag meaning.

An independent review of the change. Neither does “LGTM”.

adversarial reviewU · UNIFORM

“You are running into danger.”

Try hard to break it before calling it done.

integrateD · DELTA

“Keep clear of me; I am manoeuvring with difficulty.”

Bring in newer work from main and resolve conflicts.

ask youV · VICTOR

“I require assistance.”

Questions from the crew

Anything else, ask on GitHub.

Do I need a Jev key?

To let Jevellan steer itself, yes. Without one you pick each step yourself (flag G: “I require a pilot”). There's no rulebook to fall back on. We threw it overboard.

Will it touch my ~/.claude or ~/.codex?

No. Jevellan keeps its own homes under ~/.jevellan, one per account. Your settings, logins and memory stay exactly as they are.

Can it push to my main branch?

Only Jevellan publishes, only when the work is done, only after its own test run passes on the final commit, and never with --force. Agents don't push.

Can I use my Claude subscription?

Jevellan uses the accounts you give it. Anthropic's terms restrict third-party tools from offering Claude subscription logins without their approval. Jevellan has no such approval, so using your own subscription token is your decision. API keys always work.

What if I disagree with Jev?

Change any step afterwards: override and undo, or just override. It never stops to ask first, and your corrections shape its next decisions.

Which agents and models does it work with?

Claude Code and Codex first, with every model they offer. Gemini CLI, OpenCode, Pi and more are next, each through a berth. Anyone can write a berth: one contract, and a test kit that says when it works.

Why the name?

Jev plus Magellan. Jev itself is reportedly a wink at the Jevons paradox. Magellan, Fernão de Magalhães, was a Portuguese navigator who sailed around the world for Spain. Jevellan is Portuguese too, and sails for everyone.

Is it ready?

It's v0.1 and freshly launched. Expect weather. Issues and pull requests are very welcome.
